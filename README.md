# 域名分流规则库

统一收纳域名分流资料，区分实际使用规则、外部候选来源与变更记录。目标客户端为 OpenClash、Clash Verge 和 iOS 小火箭；各端的完整配置和运行设置分别管理。

## 当前状态

2026-10-30 创建公开仓库。本次仅建立中文说明、来源登记和记录入口，尚未导入正式域名规则、生成客户端规则集或连接任何设备。当前仓库不能作为可部署的完整配置使用。

## 内容入口

- [变更记录](CHANGELOG.md)：逐次说明新增、修改、删除及其影响。
- [正式规则区](正式规则说明.md)：只有明确纳入正式发布的规则才由客户端引用；当前为空。
- [外部来源与候选区](外部来源.md)：登记外部仓库和待检查资料；收纳不等于启用。

## 管理方式

外部来源先检查许可、版本、变化和分类冲突，再与已确认的定向例外整合；完成适用检查后才发布正式规则。公共域名名单可以共享，三端语法分别生成，端口、TUN、DNS接管和进程设置不混用。

维护者通过 Git 提交保留文件变化；CHANGELOG.md 记录人能读懂的原因、增减范围和核验状态。候选文件不作为正式版本；失败更新不覆盖上一份有效正式规则。

## 隐私与来源

不上传机场订阅、节点地址与密码、访问令牌、家庭内网地址、访问日志或包含凭据的完整配置。外部资料按原许可处理，未确认许可的来源先仅登记链接，不整份复制发布。

本仓库尚未选定自编内容的统一开源许可证；公开可见不代表第三方内容可以任意复制，第三方资料仍遵守其原许可。
